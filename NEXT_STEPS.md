# Qué queda por hacer (depende de ti)

1. Crear repositorio GitHub y subir esta carpeta; conectar con Netlify (ver README).
2. Editar `data/config.json`: `site_url`, titular (`owner`), correo y `legal_reviewed` cuando un profesional revise los textos.
3. Configurar `admin/config.yml` (`repo`, `site_url`) y activar el proveedor OAuth de GitHub en Netlify; probar `/admin/`.
4. Sustituir los 7 productos de demostración por reales: enlace de afiliado, tienda, precio, fecha de verificación, imagen propia y licencia.
5. (Opcional) `cookies.ga4_id` para analítica; `newsletter.action` con la URL de tu formulario (Brevo/MailerLite).
6. Tras publicar: probar el formulario de contacto, enviar el sitemap a Search Console y revisar la política de cada programa de afiliación (avisos obligatorios → campo `affiliate_note`).
